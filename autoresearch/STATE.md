## Current Doctrine

This system exists to compound the user's AI operating system every 14 days.

The loop is not an AI-news digest. It is a governed research-and-behavior-update mechanism.

Core doctrine:

1. Every run must read prior state before researching.
2. Every run must distinguish fact, inference, speculation, and recommendation.
3. Every run must produce at least one reusable artifact: policy, prompt, workflow, experiment, evaluation harness, Ponder canvas pattern, or retired assumption.
4. Every run must leave behind a better next-run queue.
5. Every 3 runs, durable signal is compacted into this state file.
6. Every 6 runs, governance policies are audited.

## Active Operating Principles

- Treat prompts as one layer of a broader context system.
- Treat GitHub as source-of-truth memory and version history.
- Treat Ponder as exploration and synthesis substrate.
- Treat ChatGPT/Deep Research/Agent mode as reasoning and research engines.
- Use Exa-style semantic discovery for non-obvious sources.
- Use Tavily-style targeted extraction for bounded verification and source control.
- Use retrieval budgets to avoid endless search and context sludge.
- Use decision traces so the system remembers why doctrine changed.
- Convert prior run outputs into behavior changes, not just notes.
