## Purpose

This task scouts frontier-grade AI resources, tools, workflows, framework systems, prompt/context packs, agent templates, MCP servers, browser automation patterns, and monetizable AI operating-system packages.

It is intentionally offset from the biweekly AutoResearch task. The Scout task discovers and maps raw resources. The AutoResearch task decides what should become doctrine, experiments, or build work.

## Current Thesis

The next upgrade beyond prompt packs is context/action packs.

A context/action pack is a reusable bundle containing:

- operating brief
- domain doctrine
- source map
- prompt library
- tool/API schema
- browser workflow
- example inputs/outputs
- eval suite
- deployment checklist
- decision trace policy

This is more valuable than a prompt because it gives an AI agent enough context, tools, and validation criteria to build or operate an actual system.
